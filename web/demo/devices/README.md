# Devices — phones and screens as recipes

Data recipes for the `architecture` op (module `assembly`). They are generated by no
native code; every number is an editable input.

| File | Instance | Screen part | Inputs |
|---|---|---|---|
| `smartphone.json` | `phone` | `scr` (+z face) | height, width, depth, corner, lift, bezel, punch, lenses, lens_size, island (0 square, 1 pill, 2 bar), bump, body_r/g/b, frame_tone |
| `wall_screen.json` | `screen` | `scr` (+z face) | width, aspect, depth, bezel, corner, stand, neck, lift, tone |

Put a live screen on the part with the generic `display` op:

```json
{"op":"display","id":"phone_screen","instance":"phone","part":"scr","mode":"view",
 "camera":{"kind":"fixed","eye":[6,3,8],"target":[0,0.8,0],"fov":40},"radius":0.0071}
```

`mode` can also be `image` or `video` with `src` (a local file). The plugins
`smartphone`, `wall_screen` and `phone_showcase` (`plugins/*.plugin.json`) add these
recipes with their screen in one step: **HUD > Plugins**, or MCP
`scene.controls {request:{command:"plugin_add", plugin:"phone_showcase"}}`.

Guide: `prompt/guides/displays-and-plugins.md`.
