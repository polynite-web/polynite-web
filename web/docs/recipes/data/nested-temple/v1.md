## Prompt

In Polynite, compose a detailed Japanese pagoda from nested assemblies. Define a bracket group, repeat it in a frontage, repeat the frontage around a storey, then repeat uniformly scaled storeys with taper. Use shared swept roof panels and ribs, procedural vermilion wood, dark tiles, warm paper and gold fittings. Keep storey count, width, taper, eave lift and detail switches editable. Treat this recipe as a starting point: invent other structures using the same operators. Estimate before applying, inspect bounds and observe the rendered result. Preserve the current scene.

## Recipe composition

1. Define reusable mesh prototypes and local bracket/frontage/storey assembly definitions.
2. Compose bounded assembly calls with local translation, yaw, uniform scale and repeat.
3. Apply procedural material roles, inspect the flattened plan and actual GPU sharing, then observe and save.

## Limits

Realtime parametric study inspired by the proportions and layered detail of Golden Temple. It does not reproduce the reference offline renderer, complete landscape or every architectural ornament. Assembly transforms use uniform scale and yaw; individual leaves retain full rigid rotation. Nested leaf animation is rejected. GPU sharing depends on compatible materials and scales.

Recipes are editable examples, not a closed list of shapes. Compose or invent alternatives using the connected engine's discovered operators. Geometry and motion execute locally; the server distributes recipe data.
