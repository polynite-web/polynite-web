# One toolkit. Three flowers.

Compose petals, leaves and a folded lip from shared surfaces, then animate their opening.

Version: 1; desktop verified 2026-10-16 at 94824df40. Browser: not verified; do not assume support.
Required scene.capabilities.commands flags: recipe_program.
Operators: surface, primitive, repeat, motion, expression.

## Prompt

In Polynite, compose a pink lotus, a daisy and an orchid from editable assembly recipes, using shared surface, repeat and motion operators. Give their petals a smooth four-second opening loop. Keep each flower independently editable. Expose petal count, shape, colour and opening controls. Use the linked example as a starting point, then invent your own variation.

## Recipe composition

1. Shape one petal with a reusable curved surface.
2. Repeat it around a centre; arrange additional layers in the recipe.
3. Add leaves and a central piece, then articulate the petals with motion.

## Settings

Scene settings > Living architecture > select lotus, daisy or orchid > Parameters: shape / profile / materials / animation. Set animate = 1, duration = 4, then Play.

## Try a variation

- Set animate to 0 and vary opening from 0 to 1.
- Change petal count and profile to invent a fourth flower.
- Enable animate and compare the closed and open poses.
