Get started

  1. Open Polynite in a desktop browser with WebGPU. Use procedural scene controls, or connect a compatible assistant using the MCP integration.
  2. Start small: create a few objects, inspect them and keep editing. Positions use metres; blocks of 0.25–0.4 m are a useful starting point.
  3. For conversational creation, ask in the connected assistant. Follow-ups target the same scene; a lost connection should be recovered before further edits.

No imported GLB is required to begin. Watch Polynite demonstrations on YouTube ↗

Small things to try

A colourful tower

Create a compact tower of colourful blocks.

Expected: new blocks, framed camera and existing content preserved.

A small edit

Make the top block yellow.

Expected: an edit in the same scene. Ambiguous references may need a scene summary.

Physics

Add a few physical blocks beside the tower.

Expected: grabbable dynamic bodies. The native floor already supplies the ground.

A scene bubble

Add a mint speech bubble saying “Hello!” above the blocks.

Expected: text visible without recording. Controls provide visibility, clear and undo.

A moving title

Put a ring of letters around the model and make it rotate slowly.

Requires a loaded model, or an explicit world anchor. Layout, style and appearance can be combined.

Record from the beginning

Prepare an explosion of the blocks. Grow the title “Explosion”, fade it out when the explosion begins, and record a 5-second MP4.

Prepare the scene and animation first. Recording starts from zero, restores the starting state and returns to normal view. Text is hidden after a successful film by default; explicitly ask to keep it if desired.

Find your film

Open Gallery → Videos. Use preview/download. When cloud transfer succeeds, the assistant can provide full temporary URLs. A filename or native path is not a web download link.

Download films you want to keep. Uploaded MCP videos have seven-day retention. Read links expire within one hour and can be refreshed while the file remains available. Anyone holding a signed link can view its video until expiry.

Current limits

  • Rendering requires WebGPU and a ready viewer for scene edits.
  • Cloud uploads: 32 MiB/video, 16 videos/scene, 12 new uploads/account/day.
  • Recording accepts 30/60 FPS and 720/1080p. Encoder availability/formats depend on the browser.
  • MCP checkpoints retain data for seven days. Missing model files may need to be supplied again.
  • Long Firefox sessions have an unresolved memory-crash report. Firefox endurance and mobile/Safari recording are not certified.
  • Complex articulated scenes require verification. Command acceptance does not prove a correct visible result.

See troubleshooting.

Models, providers and access

Importing and inspecting a local model is separate from sharing or using an AI service. Sharing, checkpoints and cloud video delivery can upload data; connected generation providers may require an account and charge for usage. See data handling.

Jev connections inside the app, Polynite credits and local AI are foundations in development, not public features of the current MCP integration. The plugin has not yet been approved for the public OpenAI directory.
