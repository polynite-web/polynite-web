The assistant prepares commands; Polynite validates them and runs them in your connected viewer.

Connect

The production endpoint is https://mcp.polynite.io/. Add it through your host’s remote MCP connection flow, sign in and review permissions. Directory availability is not claimed before approval.

  • ChatGPT / Codex: use the remote MCP/developer connection flow available to your account. Select Polynite when asking for a scene.
  • Claude: add a custom remote connector if supported by your account. Keep the original view available.
  • Other clients: HTTPS JSON-RPC with OAuth. Without a persistent conversation context, keep the returned scene_id explicitly.

Exact fields, small operations

Read polynite_operation_help for a schema/minimal example, even without a live scene. Check capabilities for runtime support.

{"operation":"record_video","action_id":"fresh-unique-id","duration":5}

Defaults: landscape, 1080p, 60 FPS, start from zero, restore the scene and hide text afterwards. Query video_status, then video_links. Do not record again while the first operation runs.

{"operation":"text_upsert","action_id":"another-unique-id","item":{"id":"hello","text":"Hello!","position":[0,2,0],"color":"#93e2b9"}}

Understand the result

  • observed: a read returned information.
  • accepted: command accepted; visual inspection is separate.
  • in_progress: recording/transfer underway; query status.
  • completed: completion reported; check file availability/rendering.
  • rejected: correct the request using the error.
  • unknown: inspect this scene before another mutation. Never blindly replay.

Other models

Smaller tool-calling models use the same operations. A typed-decision adapter can choose an operation and let code construct arguments. Confidence never grants permission. Live Jev inference is not yet certified.
