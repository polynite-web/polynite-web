An MCP server for a 3D scene

Polynite exposes what it builds with to programs: an agent such as Claude Code can create objects, move them, read the scene back and correct itself, in the same window you are looking at. It is a preview, and this page says what works today.

Open Polynite, press Create, then Agent

What an agent can do

  • polynite_capabilities - the grammar: ops, primitive types, materials, units.
  • polynite_describe - every object with position, rotation, scale, colour and material, the selection, the lamps, the sun, the camera.
  • polynite_apply - a batch of actions: create, set, move, rotate, scale, place on, duplicate, delete, group, camera, sun, lamps. All or nothing: a refused action refuses the batch and says why.
  • polynite_undo, polynite_redo, polynite_select, polynite_snapshot, polynite_load.
  • polynite_bake and polynite_export - the creation as a GLB file, loaded back as a model or just written.

Connect Claude Code

On the desktop app, open the door in Create > Agent, then:

claude mcp add --transport http polynite http://127.0.0.1:8790/mcp

Ask for a castle beside the model, or a table with chairs, and watch it appear. The agent reads the scene back after every batch, including the sentence Polynite wrote for each refused action, so a wrong move is corrected rather than repeated.

On the web: a room

A page cannot listen on a port, so the web app listens on a room: open the door and the page shows a room name. A tool posts its requests to that room and the page answers them. Nothing outside your window can reach the scene while the door is closed.

The actions, in short

{"op":"create","id":"pedestal","t":"cube","p":[0,0.25,0],"s":[1.6,0.5,1.6],"c":"#c8c0b0","m":"stone"}
{"op":"create","id":"ball","t":"sphere","p":[0,1,0],"s":0.9,"c":"#d02a20"}
{"op":"place","id":"ball","on":"pedestal","side":"top"}
{"op":"camera","frame":"all"}

Units are metres and degrees, up is +Y, the floor is y = 0, primitives are one metre and centred. The loaded GLB is the object model and can be moved and scaled like the others.

Status

Preview. The desktop app and the web page both answer; the door is off by default and carries no secret yet, so keep the room name to yourself. Heavy creations, materials in the exported GLB and a shared server address are being worked on.
