Studio

A temple, built from shared parts.

Compose brackets into frontages, frontages into storeys, and storeys into a tapered pagoda. Curved hipped roofs, visible ribs, lattice panels and gilt fittings remain editable recipe data.

Open & test ↗Explore the recipe →Get the scene
Three-storey gatewayCompact five-storey tower
Make your own version
In Polynite, compose a detailed Japanese pagoda from nested assemblies. Define a bracket group, repeat it in a frontage, repeat the frontage around a storey, then repeat uniformly scaled storeys with taper. Use shared swept roof panels and ribs, procedural vermilion wood, dark tiles, warm paper and gold fittings. Keep storey count, width, taper, eave lift and detail switches editable. Treat this recipe as a starting point: invent other structures using the same operators. Estimate before applying, inspect bounds and observe the rendered result. Preserve the current scene.

Reference: https://explore.polynite.io/docs/recipes/nested-temple/
