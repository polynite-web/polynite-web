01 / COMPOSE

How the recipe works

  1. Publish named horizontal reservations as footprint nodes, without duplicate render geometry.
  2. Measure each candidate against explicit sources; preserve the complete-object radius plus margin, then choose the first free candidate.
  3. Attach reused objects to the chosen terrain-seated anchor; validate spacing pairs and keep all rules in editable recipe data.

The engine supplies operators. The recipe chooses their arrangement, materials and behaviour. Change the composition to invent a different structure.

02 / ASK

Start a conversation

In the current Polynite scene, compose editable placement recipes using named footprint reservations. Discover commands.recipe_footprints and operators footprint/context/spatial/let. Declare conservative roof, canopy and access rectangles, bind only explicit nearby sources, and preserve a whole-object radius plus clearance margin. Try a preferred position and four bounded alternatives; reject atomically if none fits. Add explicit pair constraints between placed objects. Keep geometry, aesthetic choices and candidate rules in JSON recipes; reuse existing geometry and terrain operators. Estimate, apply with stable IDs, inspect bounds and actual pixels. Preserve user edits and locks; do not clear the current scene.

Example and versioned recipe: https://explore.polynite.io/docs/recipes/footprint-placement/

Paste into your connected assistant. A prompt invites a new interpretation; the scene and JSON preserve this exact reference.

03 / VERIFY

An example you can test.

These expectations are also consumed by the regression runner. Check geometry and behaviour, then look at the result.

  • placement · place · observed at 0 / 2.8 / 5.6 seconds

Horizontal declared reservations, not automatic arbitrary-mesh bounds, 3D collision, global packing or pathfinding. Each slot tries five recipe-defined candidates against at most seven explicit reservations; pairs are checked in groups of up to six. In this garden, path reservations conservatively enclose the complete sine bend and can exclude extra space. Radius must contain the complete attached object; update it if geometry grows or is manually changed. No position fits: reject and preserve the previous scene. Candidate changes happen at edit-time or explicit film cues, not continuously during physics.

For assistants & developers

Requires commands.recipe_program, commands.recipe_context, commands.recipe_spatial, commands.recipe_terrain, commands.recipe_footprints from the connected engine. Discover operators before composing, estimate before applying, and preserve user edits.
