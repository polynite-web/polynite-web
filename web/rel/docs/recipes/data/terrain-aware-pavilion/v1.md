## Prompt

Create a Japanese garden pavilion that adapts to Polynite's infinite terrain.

- Check commands.recipe_terrain, then discover architecture.operators for spatial queries.
- Compose an assembly recipe with context:[{name:'ground',terrain:'infinite'}]. Sample four feet with height; keep the deck above their maximum plus floor_clearance.
- Choose dimensions in the recipe: an unbounded terrain has no footprint width or depth.
- Expose width, depth, roof curl and floor_clearance. Raise a broad patch of ground, then return it to the initial state in a five-second film.
- Keep the existing user scene and use stable IDs. Verify the contacts visually.

## Recipe composition

1. Declare the support as a named context reference.
2. Sample its top height at four corners and choose their maximum.
3. Place the deck above that height; extend each foot to its own sample.

## Settings

Scene settings > Living architecture > temple: floor_clearance, width, depth, curl, overhang. Adjust also exposes the scene-owned Ground height control.

## Try a variation

- Set floor_clearance to 0.6 under Scene settings > Living architecture > temple.
- Change width, depth, curl and overhang. The same support expressions still fit the feet.
- Change the raise cue depth from 4 to 2.2. Keep the ground edit broad enough for the terrain grid.

## Limits

Requires commands.recipe_terrain. Press Play to compare flat and raised ground; use Adjust for the saved controls. Terrain queries use the finest near-field triangle grid, currently 4 m. Arbitrary imported meshes and continuous terrain deformation are outside this example.

Recipes are editable examples, not a closed list of shapes. Compose or invent alternatives using the connected engine's discovered operators. Geometry and motion execute locally; the server distributes recipe data.
