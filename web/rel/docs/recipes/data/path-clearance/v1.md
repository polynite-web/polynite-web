# A path makes room.

Move or widen a path and let an editable fence reserve a clear passage around it.

Version: 1; desktop verified 2026-10-16 at 94824df40. Browser: not verified; do not assume support.

## Variants

Edit the exposed inputs to create a variation.

## Prompt

In Polynite, create a flat path crossing an editable fence. Use the path_fence assembly recipe as a starting point. Declare the path as context, measure signed distance to its corridor, and omit posts, caps and rails whose full footprint would obstruct the passage. Expose fence length, bays and clearance. Show a six-second sequence that moves and widens the path, then returns to the initial state. Preserve manual overrides and report conflicts instead of discarding them.

## Recipe composition

1. Bind the recipe to an existing path by its stable ID.
2. Measure distance from each candidate piece to the path corridor.
3. Use when to keep only pieces that leave room for their full footprint.

## Settings

Scene settings > Living architecture > fence > Parameters: shape: length, height, bays, post_width, clearance. Edit walkway in Scene settings > Adaptive construction.

## Try a variation

- Move or widen the path under Adaptive construction.
- Increase clearance and compare the opening.
- Lock a part near the passage, then move the path across it: the edit should report a conflict and preserve the previous scene.

## Limits

Flat paths only. Conditional pieces reserve a conservative radius; they do not cut arbitrary meshes. Overrides that would disappear reject the whole edit.

Recipes are editable examples, not a closed list of shapes. Compose or invent alternatives using the connected engine's discovered operators. Geometry and motion execute locally; the server distributes recipe data.
