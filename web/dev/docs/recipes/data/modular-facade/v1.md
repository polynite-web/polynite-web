## Prompt

In Polynite, build an editable operator study: Compose pilasters, window frames, sills and floor bands from shared profiles and primitive prototypes. Use the supplied JSON as a starting point, then invent a different composition. Declare reusable geometry prototypes and reference them with instance nodes. Keep profiles, layout, material roles and dimensions editable. Inspect actual instancing counters and rendered results; preserve the current scene.

## Recipe composition

1. Define a reusable shape from a primitive, profile or sweep.
2. Place instances with parameterized transforms and bounded repetition.
3. Assign shared materials; inspect geometry, save and compare the result.

## Limits

Editable operator study. Mesh prototypes are shared; nested prefab graphs and Boolean openings are not implemented. Compatible groups of four or more use GPU instancing at full detail; unsupported cases use regular rendering. Performance depends on scene and device.

Recipes are editable examples, not a closed list of shapes. Compose or invent alternatives using the connected engine's discovered operators. Geometry and motion execute locally; the server distributes recipe data.
