Three ways to create

One tap. Castles, towers, villages, forests. Tap again for another.
One sentence. Say it, shapes appear.
One picture. A full 3D model from text or an image.

Edit by hand

Tap an object: drag it, turn it, scale it. Give it stone, brick, wood, grass, water, with real relief.

One link does the rest

Send the link. Same model, same light, same framing, live, with a Remix button. Publish it and it gets its own page in the gallery.

Export a GLB, free

One standard .glb. Opens in Blender, Unity, Godot, three.js and any glTF viewer.

Let an agent build

Any MCP client can create, move and describe objects in your scene. Preview.

Requirements

A browser with WebGPU: recent Chrome, Edge, Firefox or Safari. The AI ways use a free Pollinations account.

Questions people ask

Is it free?

Yes. Creating, editing, sharing and exporting cost nothing and need no account. AI generation uses your own Pollinations credits.

Do I need to install anything?

No. A browser with WebGPU, on a computer or a phone.

Can I download what I make?

Yes, as a standard .glb.
