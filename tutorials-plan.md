# Tutorials and video signatures

Shared catalogue: stable tutorial IDs, immutable scene revisions, video/poster,
prompt, difficulty and topic. The documentation and WebGPU entry use the same
catalogue. Opening a tutorial creates an independent viewer; originals are read-only
static assets. Never publish a user's current scene as a tutorial.

- Build real procedural examples and render short MP4s through native MCP.
- Preserve/restore the active document and physics state around rendering.
- Add filtered cards, delayed muted hover, accessible large player and copy prompts.
- Open scenes directly, with explicit replay and downloadable reference documents.
- Make signature presets reusable, idempotent and independent of user content.
- Validate files by decoding MP4s, inspect frames and test real WebGPU loading.
- Preserve existing documentation redirects and verify the current engine files before publishing. Git retains previous releases.
- Subscription enforcement needs an authenticated export authority; do not claim
  a removable browser watermark is tamper-proof or change billing policy here.
