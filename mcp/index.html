An MCP server for a 3D scene

Give an agent a 3D scene. Any MCP client builds beside you: create, move, read back, correct. Preview.

Under construction. Works in the lab build, not switched on for the public site yet. MCP over HTTP, no client favoured, none required.

Create by hand todaySee the actions

What an agent can do

Create primitives, set materials and colours, move, rotate, scale, place one thing on another, group, light, frame the camera, undo. Read every object back with its position, so a wrong move is corrected, not repeated.

Connect a client

In the lab build, open the door in Create > Agent; the app shows the endpoint:
http://127.0.0.1:8790/mcp (streamable HTTP, on your machine).

On the web: a room

A page cannot listen on a port, so it listens on a room. Open the door, the page shows a name, the tool posts to it, the page answers. Door closed, nothing gets in.

The actions, in short

{"op":"create","id":"pedestal","t":"cube","p":[0,0.25,0],"s":[1.6,0.5,1.6],"c":"#c8c0b0","m":"stone"}
{"op":"create","id":"ball","t":"sphere","p":[0,1,0],"s":0.9,"c":"#d02a20"}
{"op":"place","id":"ball","on":"pedestal","side":"top"}
{"op":"camera","frame":"all"}

Metres and degrees, up is +Y, the floor is y = 0, primitives are one metre and centred. The loaded GLB is the object model.

Status

Preview. Heavy creations, materials in the exported GLB and a shared server address are being worked on.

Questions people ask

Which clients work?

Any client that speaks MCP over HTTP. None is favoured, none is required.

Does it need a server?

On the desktop, a local endpoint on 127.0.0.1. On the web, a room the page answers.

Is it finished?

No. The actions above work in the lab build; this page says so as the rest lands.
