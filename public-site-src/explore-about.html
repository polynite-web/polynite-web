About Polynite

A place to build.
A scene to explore.

Polynite brings procedural 3D creation, interactive physics, scene text, cinematic recording and conversational control together.

Creation comes first.

You can start with procedural objects rather than importing a model. Build through the scene controls or connect an assistant using MCP. Follow-ups keep editing the current scene instead of starting over.

GLB remains a useful part of the product: import assets, inspect their geometry and materials, choose optimization settings and use them alongside procedural elements.

Connected AI, clear boundaries.

Polynite's MCP server is deployed. A compatible assistant can prepare commands; the service validates permissions and arguments before dispatch. Public OpenAI directory approval is still pending.

Provider-key connections, Polynite credits and local AI execution are being prepared for future app integration. They are not advertised as active public features.
