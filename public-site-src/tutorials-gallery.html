Advanced

Break through a brick wall

A physical chain, procedural bricks and an impact you can tune.

Open scene ↗
Try it step by step

Build a brick wall and swing a wrecking ball on a physical chain through it. Add scene controls for impact speed, masses, release angle and friction, with gentle, breach and demolition presets. Use procedural clay and reflective marble.

Connect your assistant to recreate it, then make it your own.

  1. Watch the ball make a breach through the wall, with each chain link simulated independently.
  2. Open Scene settings and choose Doux, Percée or Démolition.
  3. Adjust impact speed, ball mass, brick mass, release angle or friction. Changes return the construction to its starting pose, paused.
  4. Use Replay to run the existing sequence with the new values, without recording.
  5. Save scene keeps your settings and the sequence for later.
  6. Ask your assistant to add different custom controls to another scene: each scene owns its own panel.
MCP example

This changes the impact settings of the opened scene and returns it to the start, paused. Use settings_replay to compare the result. These controls require an updated Polynite viewer.

Use polynite_scene with these arguments and a fresh action_id. Keep the current scene.

{
  "operation": "settings_set",
  "action_id": "replace-with-a-fresh-uuid",
  "values": {
    "impact_speed": 7,
    "ball_mass": 100
  }
}

MCP example

This snippet adds the illustrative command field only. The blue colour change is a separate action in the downloadable scene.

Use polynite_scene with operation: local, method: scene.cinematic, a new action_id, and this object as params.request. replace changes the whole timeline; keep existing steps when editing.

{
  "command": "replace",
  "seq": [
    {
      "op": "hold",
      "at": 0,
      "dur": 4
    },
    {
      "op": "text",
      "preset": "command-input-v2",
      "text": "Make it blue",
      "at": 0.4
    }
  ]
}

polynite-ending-v4

Keep the Polynite signature, choose its placement and soften its sound.

Open scene ↗
Try it step by step

Use polynite-ending-v4 for this film. Put the closing signature higher with the short-portrait layout and lower its sound volume to 0.5.

Connect your assistant to recreate it, then make it your own.

  1. Exports install the required signature automatically; creation prompts do not need to mention it.
  2. For a custom ending, stop the film and install polynite-ending-v4.
  3. Choose default or short-portrait placement and adjust volume. The fade, shine-only bloom and quiet cues stay together.
  4. The signature remains required at export; paid removal is not enabled.
MCP example

Use polynite_scene with operation: local, method: scene.cinematic, a new action_id, and this object as params.request. replace changes the whole timeline; keep existing steps when editing.

{
  "command": "set_branding",
  "preset": "polynite-ending-v4",
  "layout": "short-portrait",
  "volume": 0.5
}

From scene to MP4

Record a smooth film, preview it and keep your own copy.

Try it step by step

Record this scene from the beginning as a landscape MP4 at 1080p and 60 FPS. Keep the sounds subtle, then show me where to download the video.

Connect your assistant to recreate it, then make it your own.

  1. Prepare a film with the scene and camera moves. Save a .scene copy if you want to edit it later.
  2. Record from the beginning; do not pre-play the film. Choose landscape or portrait and 30 or 60 FPS.
  3. After recording, open Gallery > Videos. Preview with sound, then download the MP4 or use Open folder on desktop.
  4. A .scene stays editable. An MP4 is the rendered movie. A Mint Link opens the interactive creation.
  5. Download cloud videos you want to keep: uploaded MCP videos have seven-day retention.
