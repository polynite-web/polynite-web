Same scene, successive changes

Follow-ups target the bound scene. If the viewer disconnects, restore the original view when possible; an offline scene does not authorize replacement. Command acceptance is separate from visual verification.

Local MCP

The native application can expose a local MCP connection while it is open. Use its MCP connection panel to start the endpoint and copy its current address. Local connectivity and the authenticated remote connector are different access paths.

Supported workflows and limits

Scene creation, incremental edits, physics, scene text and cinematic recording are covered by the command contract. Runtime capabilities must be checked before an action. Browser encoding, captures and restoration have documented constraints.
