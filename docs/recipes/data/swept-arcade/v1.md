## Limits

Editable operator study. Mesh prototypes are shared; these studies use mesh instances; nested composition is demonstrated separately in the architecture workshop. Boolean openings remain separate. Compatible groups of four or more use GPU instancing at full detail; unsupported cases use regular rendering. Performance depends on scene and device.

Recipes are editable examples, not a closed list of shapes. Compose or invent alternatives using the connected engine's discovered operators. Geometry and motion execute locally; the server distributes recipe data.
