One toolkit. Three flowers.

Compose petals, leaves and a folded lip from shared surfaces, then animate their opening.

Make it yours.

Scene settings > Living architecture > select lotus, daisy or orchid > Parameters: shape / profile / materials / animation. Set animate = 1, duration = 4, then Play.

  1. Set animate to 0 and vary opening from 0 to 1.
  2. Change petal count and profile to invent a fourth flower.

01 / COMPOSE

How the recipe works

  1. Shape one petal with a reusable curved surface.
  2. Repeat it around a centre; arrange additional layers in the recipe.
  3. Add leaves and a central piece, then articulate the petals with motion.

The engine supplies operators. The recipe chooses their arrangement, materials and behaviour. Change the composition to invent a different structure.

02 / ASK

Start a conversation

In Polynite, compose a pink lotus, a daisy and an orchid from editable assembly recipes, using shared surface, repeat and motion operators. Give their petals a smooth four-second opening loop. Keep each flower independently editable. Expose petal count, shape, colour and opening controls. Use the linked example as a starting point, then invent your own variation.

For assistants & developers

Requires commands.recipe_program from the connected engine. Discover operators before composing, estimate before applying, and preserve user edits.

Minimal native edit after opening the example; stop playback before editing:

{
  "actions": [
    {
      "op": "architecture",
      "id": "lotus",
      "params": {
        "opening": 0.800000012
      }
    }
  ]
}

Send via scene.apply. The value shown is the recipe default; change it within the input bounds in the JSON. Remote MCP clients should discover their current tool schemas instead of assuming this native envelope.
