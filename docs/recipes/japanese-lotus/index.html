Make it yours.

01 / COMPOSE

How the recipe works

  1. Compose shared geometry and material operators from the recipe JSON.
  2. Bind explicit supports or paths where needed, retaining stable IDs.
  3. Expose parameters; verify changes, relationships and playback before saving.

The engine supplies operators. The recipe chooses their arrangement, materials and behaviour. Change the composition to invent a different structure.

Stylised procedural study. Explicit analytic cube supports and flat named paths; no arbitrary terrain fitting or roof unions. Animation articulates cached petals; landscape changes occur at edit time.

For assistants & developers

Requires commands.recipe_program, commands.recipe_context, commands.recipe_spatial from the connected engine. Discover operators before composing, estimate before applying, and preserve user edits.

Minimal native edit after opening the example; stop playback before editing:

{
  "actions": [
    {
      "op": "architecture",
      "id": "lotus",
      "params": {
        "opening": 0.800000012
      }
    }
  ]
}

Send via scene.apply. The value shown is the recipe default; change it within the input bounds in the JSON. Remote MCP clients should discover their current tool schemas instead of assuming this native envelope.
