Architecture / RECIPE 1

A garden you can shape.

Recipe-authored gold handles reshape a connected temple and gallery. Move a source, retain its doorway and roof links, and save your own edition.

Three editable versions: original, Compact hall, short gallery and Broad gallery, raised roof. Choose Variant in the viewer.

Make it yours.

Open & test → Adjust → hall / gallery · recipe controls. Connection controls set passage width and height. In the engine HUD, Living architecture → Find connection ports previews targets, then Connect and align. Detach keeps the current position. Floor reflections are enabled. Recipe input.handle binds an axis and numeric local origin to an existing bounded input. It is a value guide, not a guarantee of silhouette fit. Other controls remain sliders.

  1. Pause, then Open construction handles → hall → Shape. Drag a gold ruler; release to apply or Escape to cancel.
  2. Select gallery by its base dot, or choose it in Constructions. Shape controls stay available while its root remains attached.
  3. Choose Move on hall to move the source and its dependent gallery together. Detach a consumer explicitly before moving it freely.
  4. Adjust retains every numeric recipe slider. Save my scene keeps handle declarations, values and connections.

01 / COMPOSE

How the recipe works

  1. Open & test; pause playback before editing.
  2. Open construction handles. Choose Shape, Move or Rotate in the Constructions HUD.
  3. Click a base dot to select; drag a gold handle and release once. A refusal preserves the last valid building.
  4. Use Adjust for variants, precise numeric controls and connection tools. Save an independent .scene.

The engine supplies operators. The recipe chooses their arrangement, materials and behaviour. Change the composition to invent a different structure.

03 / VERIFY

An example you can test.

These expectations are also consumed by the regression runner. Check geometry and behaviour, then look at the result.

  • roof_link · gallery · observed at 0 / 3 / 6 seconds
  • port_link · gallery · observed at 0 / 3 / 6 seconds

Explicit directed ports, not global welding. Entry targets must come from real wall opening exports. The consumer connector is a root typed anchor with input-only pose and dimensions; no nested, context-dependent or repeated from port. Entry/wall fit compares width and height; floor/support fit compares width and depth. The target is not enlarged automatically. Preview checks interfaces and cycles; estimate also checks geometry, roof contact and overrides. Detach before moving a constrained consumer. No automatic obstacle routing or arbitrary mesh Boolean. Gold guides preview proposed values; geometry rebuilds and validates only on release. Input handles use numeric local origins, so they do not automatically follow other recipe dimensions. Move/Rotate are disabled for attached roots. No general Boolean, obstacle route finder or global layout solver.

For assistants & developers

Requires commands.recipe_program, commands.recipe_assemblies, commands.recipe_instances, commands.recipe_junctions, commands.recipe_roof_ports, commands.recipe_context, commands.surface_prisms, commands.recipe_connections, commands.recipe_handles from the connected engine. Discover operators before composing, estimate before applying, and preserve user edits.

Minimal native edit after opening the example; stop playback before editing:

{
  "actions": [
    {
      "op": "architecture",
      "id": "hall",
      "params": {
        "rise": 1.5
      }
    }
  ]
}

Send via scene.apply. The value shown is the recipe default; change it within the input bounds in the JSON. Remote MCP clients should discover their current tool schemas instead of assuming this native envelope.
