Privacy

Polynite is operated by Majify Technologies Inc., Quebec, Canada. Contact: contact@majify.tech.

Data used to provide the service

We process scene instructions, object data, text and files you provide for creating, rendering, recording or sharing. Connected assistants have their own privacy policies. Polynite receives the tool arguments and data the host sends, not an automatic copy of every conversation.

GitHub sign-in reads an account identifier and public profile. Separate repository/storage integrations require their own permissions. OAuth grants, scene handles and browser keys help authorize the correct account and scene. Credentials are not intended for chat output.

Browser and cloud storage

The engine renders in the browser. Local settings and gallery movies can remain in browser storage until you clear them. New MCP movies can upload to private Cloudflare R2 so the assistant can return preview/download links.

MCP checkpoints and uploaded MCP movies have seven-day retention. Read links expire within one hour; anyone holding a link can read its video during that period. A new link can be requested while the file remains available. These temporary files are not a permanent backup.

Other features have separate retention: anonymous shared uploads are configured to expire after 72 hours; archives use a 30-day window, count limits and cleanup/grace rules. Files stored in your own connected provider remain subject to that provider and your settings. Public documentation movies are deliberately public samples.

Providers and logs

Cloudflare hosts code and stored content. GitHub supports sign-in and optional integrations. Your chosen assistant host processes conversation/tool data. Operational logs may include timing, errors, IP/request metadata and service identifiers for security and troubleshooting. We do not intend to log OAuth tokens or private video link credentials. Provider log retention and feature storage can differ from the seven-day MCP content period.

Data may be processed outside Canada by infrastructure providers. We use service data to operate, secure and troubleshoot Polynite, respond to support requests and meet applicable obligations. We do not sell your scene content.

Your choices and requests

Download important movies. Clear local data through browser storage controls. Sharing a scene or link gives recipients access according to that feature. Contact us for access, correction, deletion or privacy questions; we may verify your identity. Requests are handled subject to applicable law and technical/legal retention requirements.

Changes

We update this page when data handling changes. The date above identifies this policy version. Contact us for clarification about a particular feature or provider connection.
