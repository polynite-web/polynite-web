01 / COMPOSE

How the recipe works

  1. Define named roof wings and their recipe-owned profiles.
  2. Reference the roof from a wall chain; declare real door and window voids.
  3. Compose shared columns, brackets and ornaments; estimate, inspect, capture, save and reopen.

The engine supplies operators. The recipe chooses their arrangement, materials and behaviour. Change the composition to invent a different structure.

02 / ASK

Start a conversation

In Polynite, discover architecture.operators for roof and wall and check commands.recipe_junctions. Compose an editable Japanese temple from a local joined roof and mitered wall chain. Cut the door and windows as real openings. Keep curvature, door width, materials and ornament choices in a module:assembly recipe; use shared prototypes for columns and repeated brackets. Estimate before applying. Change the roof rise and door width, inspect contacts and voids, save, reopen and resume by patching the same instance ID. Preserve the current scene.

Example and versioned recipe: https://explore.polynite.io/docs/recipes/joined-temple-garden/

Paste into your connected assistant. A prompt invites a new interpretation; the scene and JSON preserve this exact reference.

03 / VERIFY

An example you can test.

These expectations are also consumed by the regression runner. Check geometry and behaviour, then look at the result.

  • junction · hall · observed at 0 / 3 / 6 seconds

Bounded local joins: up to four roof wings, level wall chains and rectangular openings. Roof upper faces are trimmed at intersections; underside seams are not a general solid Boolean. Separate wall chains are not globally welded. Style, profiles, ornaments and placement remain editable recipe data.

For assistants & developers

Requires commands.recipe_program, commands.recipe_assemblies, commands.recipe_instances, commands.surface_profiles, commands.surface_paths, commands.recipe_junctions, commands.surface_prisms, commands.recipe_context from the connected engine. Discover operators before composing, estimate before applying, and preserve user edits.

Minimal native edit after opening the example; stop playback before editing:

{
  "actions": [
    {
      "op": "architecture",
      "id": "hall",
      "params": {
        "rise": 1.5
      }
    }
  ]
}

Send via scene.apply. The value shown is the recipe default; change it within the input bounds in the JSON. Remote MCP clients should discover their current tool schemas instead of assuming this native envelope.
